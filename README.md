# 📚 Mon Planning Intelligent

Une application pour aider les élèves à optimiser leur temps entre cours et tâches domestiques.

## 🚀 Fonctionnalités

- ✅ Gestion de l'emploi du temps scolaire
- ✅ Gestion des tâches domestiques et d'étude
- ✅ Optimisation automatique du planning
- ✅ Recommandations personnalisées
- ✅ Statistiques de progression

## 📦 Installation

```bash
# Installer les dépendances
cd backend
npm install

# Lancer le serveur
node server.js
